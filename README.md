# Nextel for 4chan-X

Plays a classic Nextel chirp when 4chan X detects a new post quoting you.

[Install userscript](https://raw.githubusercontent.com/gorpix/Nextel-for-4chan-X/main/nextel-for-4chan-x.user.js)

Keep 4chan X's built-in **Beep Quoting You** option disabled. Use the `[Chirp]` header button to test the sound.
